# منصة التحليل التعليمي للفوركس 📊

هذا المستودع يحتوي على الكود المصدري لمدونة تعليمية متخصصة في تحليل أسواق المال، مبنية باستخدام **Jekyll** ومستضافة على **GitHub Pages**.

## 🚀 المميزات
- **نظام مقالات (Blog):** شروحات تعليمية وتحليلات يومية.
- **متوافقة مع الجوال:** تصميم متجاوب بالكامل.
- **تحسين محركات البحث (SEO):** إعدادات جاهزة للأرشفة.
- **روابط إحالة مدمجة:** لدعم العمل وتحقيق العوائد.

## 📁 هيكل المشروع
- `_layouts/`: القوالب الرئيسية للصفحات.
- `_includes/`: الأجزاء المشتركة (Header, Footer, Sidebar).
- `_posts/`: المقالات والتحليلات (بصيغة Markdown).
- `assets/`: الملفات المساعدة (CSS, Images, PDF).
- `pages/`: الصفحات الثابتة (أدوات المتداول، من أنا، إلخ).

## 🛠️ كيفية التعديل
1. قم بتعديل ملف `_config.yml` لتغيير الروابط والمعلومات الشخصية.
2. أضف مقالاتك الجديدة في مجلد `_posts/`.
3. ارفع التغييرات إلى GitHub وسيتم تحديث الموقع تلقائياً.
